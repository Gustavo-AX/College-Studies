This repository contains my studies, projects, exercises, and other academic work developed throughout my college education.

The repository is organized by semester, making it easier to keep track of the subjects and projects developed during each stage of the course.

## Organization

Each folder represents a semester of the course:

```text
.
├── 2022-1/
├── 2022-2/
├── 2023-1/
├── 2023-2/
└── ...
```

Inside each semester, the content is organized according to the subjects and activities developed during that period.

This repository serves as a personal archive of my academic journey and as a way to keep my studies and projects organized in one place.
